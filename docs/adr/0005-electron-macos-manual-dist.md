# 桌面方案落地：Electron + macOS 先行 + 手动分发

Status: accepted

产品形态定为独立桌面应用后，落地三件套一并确定：技术栈用 Electron（会话分区 `persist:` 是其原生能力，正是容器隔离需要的；Tauri 包虽小但 webview 会话隔离弱，命根子需求不能赌）。OS 先只做 macOS（自用验证最快，架构上不堵 Windows 的路）。第一版手动分发安装包（下载即用），自动更新第二版再加。

## Consequences

- 包体积 ~100MB+、内存占用高，第一版接受。
- 单主窗口、容器为标签页、可分屏并排；拖出独立窗口以后再说。
