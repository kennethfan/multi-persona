# 0014 用户自定义 User-Agent（全局 + 实例覆盖）

- Status：accepted
- Date：2026-10-15

## Context

0013 落地全局纯 Chrome 伪装后，用户要求 UA 支持自定义：全局手输一份，各实例可覆盖。grill 两轮收敛：粒度选全局 + 实例覆盖（否决按站点覆盖，本次不做，记为后续迭代）；输入方式纯手输（否决预设模板）；清空语义跟随全局，形成实例自定义 → 全局自定义 → 纯 Chrome 伪装三级回退链；新导航/新标签生效，已开标签给二次确认重载；入口为设置页 + 实例右键菜单。

## Decision

- 存储：全局自定义进 `settings.json`（`Settings` 加字段，走现有 `settings:get/set`）；实例覆盖进实例记录（随实例删而删）。
- 取值：新增 `resolveUA` 纯函数实现三级回退链；校验只做 trim + 拒换行/控制字符（弹提示），长度不限。
- 生效点：复用 0013 双保险（`did-attach-webview` + `makeWebview useragent`），只换 UA 来源。
- 回显：设置页与实例 UA 弹窗各一行“当前生效 UA”只读值（读 `webContents.getUserAgent()`）。
- 否决预设模板：维护模板（Safari/Firefox/Edge…）是长期负担，手输 + 回显已够用；后续呼声高再加。

## Consequences

- 用户输错 UA 只影响自己，且回显 + 清空即跟随全局提供逃生梯；换行校验挡掉整站请求失败一类事故。
- 按站点覆盖未做：若出现“某站只要 Safari UA”的诉求，另起 ADR 讨论规则匹配与优先级。
- 验证：三级回退单测 + 手输换行被拒 + 设置页/实例弹窗回显一致 + 新标签生效 + 已开标签二次确认重载。
