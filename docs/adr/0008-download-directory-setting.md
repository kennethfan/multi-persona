# 0008 下载目录可设置

- Status：accepted
- Date：2026-10-14

## Context

下载物是会话数据的一种：不同实例登录不同站点账号，下载文件混在一个文件夹里等于另一种"串味"。
用户要求下载目录可设置，且粒度、范围、失败行为都要有明确语义。

## Decision

- 两级设置：应用级默认目录（设置页）+ 实例级覆盖（实例右键菜单"下载目录…"，可改、可恢复跟随全局）。
- 跟随语义：从未手工指定的实例跟全局走（全局变更自动生效）；已自定义的实例保持不动。
- 生效范围：`will-download` 拦截直存 + "另存为"对话框初始目录，两者都用设定值。
- 目录缺失自动创建；创建失败回退系统默认下载目录 + 通知用户。
- 重名文件自动加序号；成功下载静默，失败/回退才通知；下载列表另起一票，不在本票范围。

## Considered Options

- 只做应用级、不做实例覆盖：实现最简单，但下载物隔离不彻底，与"实例是会话单元"（0007）相悖，否决。
- 每次下载都弹框让用户选：最灵活，但高频下载场景下打扰过重，否决；"另存为"对话框已覆盖主动选择的场景。

## Consequences

- `settings.json` 加应用级字段；实例存储加可选覆盖字段（缺字段=跟随全局，老数据零迁移）。
- 主进程需接 `will-download` 设置保存路径 + 重名序号逻辑；渲染进程设置页与实例菜单各加一个入口。
