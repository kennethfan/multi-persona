# 选择浏览器扩展作为产品形态

Status: superseded by ADR-0004

用户要在同一浏览器里同屏使用同一网站的多个站点账号、互不串号。对比独立桌面应用与本地代理工具后，选择 Chromium 浏览器扩展：安装使用成本最低，最贴合“不想开隐身窗口”的痛点。

## Considered Options

- **独立桌面应用**（内嵌多个隔离浏览器视图）：隔离最彻底，但用户要换一个浏览器用，违背“现有习惯不动”的诉求。
- **本地代理/脚本工具**：偏极客，配置负担重。
- **浏览器扩展**：用户留在正在用的浏览器里，按容器隔离会话，心智负担最小。代价是隔离能力受扩展 API 约束（见后续隔离机制 ADR）。

## Consequences

- 首版只覆盖 Chromium 系（Chrome / Edge / Brave / Arc），Firefox / Safari 不做。
- 分发先走侧载自用，不上架 Chrome Web Store。
