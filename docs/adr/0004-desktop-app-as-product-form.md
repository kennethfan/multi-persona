# 选择独立桌面应用作为产品形态

Status: accepted

用户要的是独立应用体验（Dock 图标、独立窗口、不跟日常浏览混一起），浏览器扩展给不了。决定做独立桌面应用：内嵌多个浏览器视图，每个容器一个原生隔离会话分区，自带浏览器内核，不依赖本机 Chrome。

## Considered Options

- **浏览器扩展**（原 ADR-0001）：安装成本最低，但“独立应用体验”这一动机直接否决了它——扩展活在别人的窗口里。
- **管理器（调本机 Chrome 多 Profile）**：赌用户机器上有 Chrome，跨应用跳窗口体验割裂，隔离能力也受 Profile 机制约束，否决。
- **独立桌面应用**：体验完整，隔离彻底（原生会话分区，cookie / localStorage / IndexedDB 天然隔离），代价是安装包分发、体积、自动更新、多 OS 适配。

## Consequences

- ADR-0001、ADR-0003 作废（见各自 Status）。
- 隔离机制不再是难题：用原生会话分区即可，不做 shim 那一套。
- 新增待定：技术栈（Electron / Tauri）、OS 范围、分发与更新方式（Q20~Q22）。
- 扩展 frame 下定的交互（标签归属 Q12）要在桌面 frame 下重议（Q23）。
