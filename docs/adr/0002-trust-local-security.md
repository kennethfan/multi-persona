# 本机信任安全模型

容器登录态必须持久化（重启免登录），敏感数据只能存本机。决定信任本机：扩展本地存储保存，不设主密码、不加密。

## Considered Options

- **主密码加密**：启动输一次密码，数据加密存放。体验税（每次重启输密码）和实现量都不小。
- **信任本机**：前提是“这台电脑只给自己用”。第一版接受该前提，把复杂度留给会话隔离本身。

## Consequences

- 丢电脑、借电脑、恶意软件读本地文件都会直接暴露登录态；用户必须知晓该前提。
- 将来若加主密码，属数据格式迁移，成本高——本次明确为有意的阶段性取舍（见本 ADR），不是疏忽。
- 密码保存/自动登录同样不做：工具只隔离会话，不保管凭据。
